Global hotkeys: checking…

Marking works while Tradovate has focus — browser or desktop app.

Set up global hotkeys in a browser (one time)
  1. Install AutoHotkey v2.
  2. Double-click tools/trade-journal-hotkeys.ahk.
  3. Defaults: Ctrl+Alt+E entry, Ctrl+Alt+X exit, Ctrl+Alt+N note.

The desktop app needs none of this — it registers them with Windows itself.

Why starting still has to be a click

getDisplayMedia requires a real user gesture before the browser will hand over the screen, so no hotkey can begin a session. Stopping one is fine.

    Where recordings are saved

    —

    Video is written straight to this folder as ordinary .webm files — visible in Explorer, easy to back up or move to another drive, and not subject to any storage limit but the disk itself. Changing the folder affects new recordings; existing ones stay where they are.

    In a browser, recordings live in the browser's own storage and it may evict them under pressure. The desktop app writes them to a folder you choose instead.
