    Hotkeys only work while this tab is focused.

    This is a real limitation, not a bug. A page can only receive keydown while it has focus, so the moment you click into Tradovate these keys stop reaching this tab. Browsers provide no API for a page to listen globally.

    What would make marking global
    • A browser extension. A background service worker with the commands permission receives a hotkey regardless of which tab is focused, and can call the marking API here. Works across tabs; still not across applications, so it does not cover the Tradovate desktop app.
    • A desktop wrapper (Electron or Tauri). Registers an OS-level global shortcut, so marking works while any application is focused, including the Tradovate desktop app. This is the only option that covers every case.

    Both drive the same entry points: window.tradeJournal.mark({ kind }) and window.tradeJournal.openTrade({ symbol, direction }), both already exposed and callable from outside this page's own key handler.

    Meanwhile: every marker you miss live can be added afterwards by scrubbing to the moment in review and marking there.
