Global hotkeys: checking…

Marking works while Tradovate has focus — browser or desktop app — as long as the local server is running and a hotkey tool is pointed at it.

Set up global hotkeys (one time, ~2 minutes)
  1. Install AutoHotkey v2.
  2. Double-click tools/trade-journal-hotkeys.ahk in the project folder. A green “H” appears in your system tray.
  3. That is it. The defaults are Ctrl+Alt+E entry, Ctrl+Alt+X exit, Ctrl+Alt+N note. Edit the top of the file to change them.

Anything that can send an HTTP request works, not just AutoHotkey — a Stream Deck, a macro keyboard, a foot pedal. They all post to http://localhost:5173/bridge/mark.

Why the in-page keys alone are not enough

A web page only receives keydown while its tab is focused, and there is no browser API that changes that. The moment you click into Tradovate, the keys below stop reaching this tab. The bridge exists because the fix has to live outside the browser.

Starting a recording still has to be a click in this tab. getDisplayMedia requires a real user gesture in the page, so no hotkey can begin a session. Stopping one remotely is fine.

Any marker you miss can be added afterwards by scrubbing to the moment in review and marking there.
